# Contributing

GUMFALL is currently in preproduction.

Before submitting a change:

1. Open or reference an issue.
2. Keep the change within the issue's scope.
3. State assumptions and unresolved questions.
4. Do not commit protected spoilers or unreleased progression details.
5. Do not claim build or test results that were not executed.
6. Keep implementation proposals separate from accepted architecture.

Submitting a contribution does not transfer ownership of the GUMFALL intellectual
property or grant permission to use the project outside this repository.
