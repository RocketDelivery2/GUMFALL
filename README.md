# GUMFALL: The Shattered Sweetlands

GUMFALL is a third-person action RPG built around responsive physical combat
between living gummy creatures.

Its defining systems include:

- Directional sword combat and weapon alignment
- Localized gummy-body integrity and limb separation
- Limb reattachment, regeneration, and prosthetics
- Playable gummy lineages and specialized classes
- Anatomy-driven monsters and royal dungeon bosses
- Material-based armor and weapon progression
- Rare natural weapon enchantments
- Competitive progression through Level 100
- Concealed progression beyond the public level cap
- Structured, normalized, and open-progression PvP
- Secret areas, royal mazes, arenas, and weekly events

## Current Phase

Preproduction and systems design.

No engine or implementation technology has been selected yet.

## Spoiler Policy

Exact secret routes, hidden-level requirements, royal-maze solutions, unreleased
content, and protected drop configurations must not be committed to this public
repository.

Private design material belongs under `design-private/`, which Git ignores.
