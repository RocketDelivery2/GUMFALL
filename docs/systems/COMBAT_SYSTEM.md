# Combat System

## GelFlow

The combat system prioritizes immediate input response, continuous movement,
readable impacts, physical consequences, and player expression.

## Authoritative Resolution

Combat resolves through:

1. Input intent
2. Action validation
3. Character movement
4. Contact detection
5. Defense and armor resolution
6. Body damage
7. Structural thresholds
8. Reaction selection
9. Presentation

## Physical Damage

Primary channels include:

- Core vitality
- Regional structure
- Stability
- Status buildup

Primary damage types include:

- Slice
- Pierce
- Crush
- Heat
- Cold
- Sour
- Sugar
- Shock
- Spirit

Every class must retain fallback combat actions after serious limb damage.
