# Competitive Progression

## Public Progression

- Levels 1–12: Class foundation
- Levels 13–30: Adventurer
- Levels 31–50: Veteran
- Levels 51–70: Heroic
- Levels 71–80: Legendary
- Levels 81–90: Mythic
- Levels 91–99: Apex
- Level 100: Transcendent

Level 50 represents a completed normal build.

Very few players worldwide should reach Level 100.

## Legacy Reroll

A character may Reroll after crossing a new ten-level milestone.

Permanent points awarded:

`floor(CurrentLevel / 10) - PreviouslyClaimedMilestone`

Example:

- First Reroll at Level 80 awards eight permanent points.
- The next eligible Reroll requires Level 90.
- Rerolling at Level 90 awards one additional point.

Each milestone can be claimed only once.

## Secret Progression

The server supports concealed progression after the public Level 100 cap.

Public documentation must not contain exact Unbinding conditions, secret proof
requirements, or future expansion thresholds.
